# Pingo Doce Plus

1. Inicie o add-on.
2. Abra a interface Web.
3. Faça o login normal no Pingo Doce uma única vez.
4. Instale e adicione a integração **Pingo Doce Plus**.

O perfil, cookies e armazenamento do Chromium ficam guardados nos dados persistentes do add-on. Depois de um reinício, o add-on reabre o mesmo perfil e a integração volta a ler os dados automaticamente.

Só será necessário repetir o login quando o próprio Pingo Doce invalidar a sessão.
